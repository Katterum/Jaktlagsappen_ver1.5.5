# Jaktlaget 1.5.5 Stable

Bygger vidare på 1.5.4.

- Valbart djurslag i hemsidans stapeldiagram: Alla, Rådjur, Dovhjort, Älg, Kronhjort eller Vildsvin.
- Information och de två senaste chattmeddelandena visas på hemsidan.
- Lagets sammanlagda jaktdagar visas i jaktstatistik.
- Tydligare kort för genomförda jakter.
- Antal registrerade jakter borttaget från passöversiktens nyckeltal.
- Medlemsredigering visar endast hektar och har rymligare fält och borttagningsknapp.
- Migrerar lokal data från 1.5.4 och tidigare versioner.
